# AENIMAL Posting Checklist

Use this before every scheduled post.

## Before Posting

- Confirm the CTA points to `https://boozelee.github.io/RhythmicRitual/` or the final ticket/access URL.
- Confirm image is from the approved asset list.
- Confirm caption includes one clear action.
- Confirm post is tagged with `Rhythmic Ritual 01: AENIMAL`.
- Confirm no placeholder email or local path is visible.

## Weekly Review

- Check which post drove the most profile visits.
- Check which visual set performed better: v2 story pass or v3 character pass.
- Save comments/testimonials into `08_Community`.
- Move best-performing captions into the next week.

## Final Week

- Replace all "request access" language with final ticket/access language if a ticket link exists.
- Pin one final access post.
- Update website hero CTA.
- Share press kit with local media and scene pages.
